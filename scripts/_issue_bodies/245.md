## Summary
Wire `fetch_news_for_pairs()` into the live trading cycle so RSS headlines (CoinDesk, Cointelegraph, Google News) appear in the per-pair block of the LLM cycle prompt. A token-budget guard ensures the total prompt never exceeds 6000 estimated tokens.

## Motivation
News context helps the LLM make better-informed BUY/SELL decisions — especially for news-driven pairs (XRP, DOGE, HYPE, SOL). Headlines only; no signal score change. The LLM decides the weight.
