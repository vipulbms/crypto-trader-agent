# Session Notes — 2026-04-05 (Part C)

## Changes

### 1. Fix Live Trading Async Bugs (kraken_client.py)

**Bug report / Feature request:** Kraken client had mismatch with the Paper Trader logic. Limit orders placed failed because subsequent SL/TP orders fired instantly before the Limit Fill returned, causing Insufficient Funds. SL/TP fallback logic cancelled native orders instead of triggering a manual market sell.

**Root cause / Motivation:**
1. Real Limit orders do not execute instantly like simulated models.
2. If SL/TP didn't execute natively (e.g. they weren't placed natively yet), fallback reasoning cancelled the orders but didn't execute the manual market sell like intended.

**Fix / Implementation:**
- Updated `check_stops_and_tp` to fetch and verify if `entry_order` has status `closed` locally first before submitting the SL/TP natively.
- Marked orders internally as `pending_fill` when placing the Limit Buy.
- Created `fallback_stop_loss` and `fallback_take_profit` statuses. If polled current price drops below them before native execution naturally occurs, `close_position` overrides by forcibly creating a Market Sell.
