# Session Notes — 2026-04-06 (Part E)

## Changes

### 1. S12.5.1: Partial Take-Profit — Full Implementation (closes #87)

**Feature request:** S12.5.1 from Epic E12 — close 50% of a position when price reaches 50% of the
TP target, then let the remaining 50% run to full TP.

**Motivation:** Locks in real profit during uptrends whilst preserving upside. Prevents the scenario
where a position reaches 80% of TP but a sharp reversal closes at SL.

**Implementation:**

#### `config.yaml`
Added `partial_take_profit` block:
```yaml
partial_take_profit:
  enabled: false              # Off by default; turn on when backtested
  trigger_pct_of_tp: 50       # Fire when price is 50% of the way to full TP
  close_fraction: 0.5         # Close 50% of remaining volume
  move_sl_to_breakeven: true  # After partial exit, move SL to entry_price
```

#### `src/exchange/paper_broker.py`

**`close_position()` — added `volume_override` parameter:**
- If `volume_override` is set, performs a partial close: reduces `volume` and `usd_value` in DB,
  sets `partial_exited=1`, position remains `status='open'`
- P&L calculated proportionally: `cost_basis = usd_value × (close_volume / volume)`
- Logs `[PARTIAL]` tag in the emoji line

**`check_stops_and_tp()` — added step 3 (Partial TP) before step 4 (full SL/TP):**
- Trigger price: `entry_price × (1 + take_profit_pct × trigger_ratio / 100)`
- Guard: `partial_exited == 0` — single-fire only
- After partial close: re-fetches position from DB (volume reduced), if still open optionally
  moves SL to entry (`move_sl_to_breakeven: true`)

#### `src/exchange/kraken_client.py`

Mirrors identical logic:
- `close_position()` updated with `volume_override` — uses `create_market_sell_order(ccxt_pair, close_volume)` for partial exit
- Does NOT cancel native SL/TP orders during partial close (they remain in force for the remainder)
- `check_stops_and_tp()` same step 1d partial TP block, queries `live_positions`

#### `tests/test_partial_tp.py`

5 unit tests covering:
- (a) Partial close fires at trigger price
- (b) Silent before trigger
- (c) Double-fire prevented by `partial_exited` flag
- (d) SL moves to entry after partial close
- (e) Wallet credited correctly (accounts for 0.26% exit fee)

All 51 tests pass (`pytest tests/`).
