# Session Notes — 2026-04-04 (Part A)

## Changes

### 1. Volatility-Adaptive Quant Migration

**Bug report / Feature request:** Transition from heuristic LLM-ranked trading to a strictly quantitative, high-frequency, volatility-adaptive system.

**Root cause / Motivation:** Improve net gain targets through rigorous mathematical modeling, dynamic profit targets aligned with volatility, and Order Book Imbalance insights.

**Fix / Implementation:**
- `src/analysis/indicators.py`: Added EMA 9, 21, and 50 momentum and trend filters.
- `src/analysis/signals.py`: Removed strict sequence rules preventing buys. Enforced Price > EMA 50 and RSI < 70 constraints.
- `src/analysis/features.py`: Implemented ATR-proportional position sizing and dynamic stop-loss/take-profit boundaries scaling between 1.75x and 4.0x.
- `src/risk/risk_manager.py`: Removed flat stop-loss rules replacing them with dynamic percentage overrides scaling against ATR.
- `src/exchange/websocket_feed.py`: Added logic to stream Kraken L2 ticker order books and expose Order Book Imbalance (OBI). 
- `src/exchange/paper_broker.py` & `src/exchange/kraken_client.py`: Moved orders from Market to Limit natively executed at the Bid to save on spread.
- `src/agent/prompts.py`: Overhauled `SYSTEM_PROMPT` to respect robust quantitative constraints at the LLM level.
- `tests/test_backtest.py`: Ported the custom test backtesting rig to utilize existing production elements like the unified `run_agent()` entrypoint and a new `HistoricalFeed`.
- `history/trades_to_candle_converter.py` & `tests/test_trade_converter.py`: Built pipeline logic to pull raw 1538142307-format logs and output compliant arrays.
