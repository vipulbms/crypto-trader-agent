# Session Notes — 2026-04-07 (Part A)

## Changes

### 1. Fix: Trading Hours Window Corrected to 06:00–04:00 SGT (22:00–20:00 UTC)

**Bug report:** Trades were being rejected with `Time-of-Day Guard: Current hour (23:00 UTC) outside allowed window (06:00 - 23:00 UTC)` even though 23:00 UTC = 07:00 SGT, which is within the intended trading window.

**Root cause:** `config.yaml` had `end_hour_utc: 23`, but `risk_manager.py` uses a strict `current_hour < end_hour_utc` check (exclusive). So 23:xx UTC was blocked. Additionally, the UTC values in config were incorrect — the comments referenced stale UTC times (16:00–20:00) from an earlier revision.

**Fix:**
- Recalculated the window: 06:00 SGT = 22:00 UTC, 04:00 SGT = 20:00 UTC.
- This is a cross-midnight UTC window. `risk_manager.py` already handles this via the `else` branch: `current_hour >= 22 or current_hour < 20`.
- Updated `config.yaml`:
  - `start_hour_utc: 22` (was 06)
  - `end_hour_utc: 20` (was 23/24)
  - Updated inline comments to reflect SGT equivalents
- Updated `.claude/skills/trading-rules/SKILL.md` Time-of-Day Guard description to `06:00–04:00 SGT / 22:00–20:00 UTC, cross-midnight`.
- No code changes required — the cross-midnight logic was already in `risk_manager.py:226–229`.

**Blocked window:** 20:00–21:59 UTC (04:00–05:59 SGT) — 2-hour dead zone.
