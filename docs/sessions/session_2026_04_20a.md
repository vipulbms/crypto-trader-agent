### 1. Fix: tz_mod stubs missing `to_sgt` — full-suite module pollution

**Bug report:** When the full test suite runs (not individual files), tests in
`test_s18_persona_cli.py` and `test_s18_regime_cli.py` failed with:
`ImportError: cannot import name 'to_sgt' from 'src.utils.tz' (unknown location)`

**Root cause:** `test_coinglass_v4.py`, `test_stale_macro.py`, `test_cycle_top_guard.py`,
and `test_btc_dominance.py` each inject a stub `src.utils.tz` module into `sys.modules`
at import time (module-level, not inside fixtures). The stub only defined `SGT`,
`now_sgt`, and `now_sgt_iso` — it did not include `to_sgt`. When `display.py` was
first imported *after* one of these test files, it hit the stub and raised `ImportError`
because `to_sgt` was missing.

**Fix:** Added `tz_mod.to_sgt = lambda dt: dt` to all four stub modules.

**Files changed:**
- `tests/test_coinglass_v4.py`
- `tests/test_stale_macro.py`
- `tests/test_cycle_top_guard.py`
- `tests/test_btc_dominance.py`

### 2. Fix: `import os` missing in `commands.py`

**Bug report:** `test_cmd_persona_set_valid` failed with:
`AttributeError: module 'src.cli.commands' has no attribute 'os'`

**Root cause:** `cmd_persona_set()` calls `os.path.join(...)` to build the config path,
but `import os` was not present in `src/cli/commands.py`. The mock patch for
`src.cli.commands.os` therefore had no target attribute.

**Fix:** Added `import os` to the imports section of `src/cli/commands.py`.

**Files changed:**
- `src/cli/commands.py`

---

### 3. Fix: NL parser keyword `"aggressive mode"` not matching `persona_set`

**Bug report:** `test_keyword_persona_set_with_target` — input `"switch to aggressive mode high"` 
resolved to `view_report` intent instead of `persona_set`.

**Root cause:** The `persona_set` keyword list did not include `"aggressive mode"`,
`"conservative mode"`, or `"medium mode"`. The input fell through to the `view_report`
branch which matched some earlier keyword.

**Fix:** Extended the `persona_set` keyword list in `src/cli/nl_parser.py` to include
`"aggressive mode"`, `"conservative mode"`, and `"medium mode"`.

**Files changed:**
- `src/cli/nl_parser.py`
