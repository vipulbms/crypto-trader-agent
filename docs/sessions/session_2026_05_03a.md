# Session Notes — 2026-05-03 (Part A)

## Changes

### 1. RAA: LLM-delegated universe decisions via MCP tools (Closes #354)

**Feature request:** Replace the deterministic gate pipeline in `research_analyst.py` with a single LLM call. Register Kraken Ticker and universe state reads as MCP-style tools the LLM can invoke. Delegate the entire ADD/REMOVE/HOLD decision to the LLM. `RiskManager.py` untouched.

**Motivation:** Centralising the decision in the LLM makes rules easier to evolve (prompt edits vs code changes) and enables holistic reasoning across all signals rather than sequential gate application.

**Implementation (`src/runtime/research_analyst.py` only):**

- **Removed** `propose_universe_addition()` — entire function replaced.
- **Added** `_build_raa_system_prompt(config, persona, universe)` — encodes all rules (persistence gate, alpha spread, persona gates, universe cap) as LLM instructions; ~1,500 tokens, keeping full call under 6,000.
- **Added** `_RAA_MCP_TOOLS` — 5 tool definitions: `kraken_ticker`, `get_universe`, `get_trend_persistence`, `get_confidence_state` (data tools), and `universe_decision` (output tool).
- **Added** `_dispatch_raa_tool(tool_name, tool_args, db_path)` — executes data tool calls from the LLM and returns JSON results.
- **Added** `_run_llm_universe_decision(pair, universe, db_path, config, ai_client)` — multi-turn tool loop (max 6 rounds); applies two hard Python guards after LLM decision:
  - **HITL lock** (S23.1.3) — substitutions routed to `hitl_queue` when lock active.
  - **Meme-block** (S22.2.1) — MEME cannot displace FOUNDATIONAL; hard-coded, no override.
- **Updated** `run_cycle()` — removed sequential gate checks; calls `_run_llm_universe_decision()` per candidate after updating `trend_persistence`.
- Max 6,000 tokens per LLM call enforced via system prompt instruction.

### 2. RAA: Full HTTP and LLM call logging

**Feature request:** Log the full HTTP endpoint + request/response for every outbound call; log each LLM call with prompt size and tool_calls returned.

**Implementation (`src/runtime/research_analyst.py`):**

- `_fetch_kraken_ticker()`: logs `HTTP GET <url>` before request; `HTTP <status> <url> (<ms>ms)` after; per-pair pipe-delimited ticker row; summary count line.
- `_fetch_coingecko_trending()`: logs `HTTP GET <url>` before; `HTTP <status> <url> (<ms>ms)` after; trending pairs pipe-delimited.
- `_classify_pair_via_llm()`: logs `LLM call|classify_pair|pair=X|prompt_chars=N` before; `LLM response|classify_pair|tool_calls=...` after.
- `_generate_rationale_via_llm()`: same pattern for `generate_rationale`.
- `_run_llm_self_critique()`: logs `LLM call|record_lesson|vectors=N|prompt_chars=N` before; response after.
- `_run_llm_universe_decision()`: logs `LLM call|universe_decision|pair=X|round=N|messages=N` per round; `LLM response|...|tool_calls=...` after each round.
