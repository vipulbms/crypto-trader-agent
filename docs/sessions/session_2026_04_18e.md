# Session Notes — 2026-04-18 (Part E)

## Changes

### 1. Heartbeat open-position detail (#268)

**Feature request:** Heartbeat Telegram message should show each open position's unrealised P&L and remaining distance to SL and TP, not just a count of open positions.

**Motivation:** The hourly heartbeat previously only reported `open_positions: N`. Operators had no visibility into which positions were open, whether they were profitable, and how far they were from their stop-loss or take-profit levels without querying the CLI separately.

**Implementation:**

`main.py` — at heartbeat time, builds a `positions_detail` list from the broker's open positions and the WebSocket feed's latest prices:
- Filters to `status == "open"` positions
- For each position: computes `_unreal_pnl = current_price × volume − usd_value` and `_unreal_pct`
- Computes `_sl_dist` (distance from current price to stop-loss, as negative %) and `_tp_dist` (distance to take-profit, as positive %)
- Passes the list to `notifier.send_heartbeat()` under key `"positions_detail"`

`src/notifications/notifier.py` — `send_heartbeat()` updated:
- Reads `summary.get("positions_detail", [])`
- If non-empty, appends a `──────────` separator and one line per position:  
  `📌 ETH/USD  +$4.12 (+2.3%)  SL:-2.7%  TP:+9.7%`
- Uses `{pnl_sign}` to ensure `+` prefix for profitable positions

### 2. Missed-signal Telegram alert (#268)

**Feature request:** When the risk manager rejects a high-conviction BUY (score ≥ 8), send a Telegram alert so the operator knows a strong signal was blocked and can investigate the reason.

**Motivation:** High-score BUY signals that are blocked by cash/position guards are invisible without tailing `agent.log`. Missing a score-8+ signal with no notification is a blind spot in a live trading context.

**Implementation:**

`src/notifications/notifier.py` — new `send_missed_signal(pair, score, max_score, reason)` method:
- Sends: `⚠️ Missed Signal: ETH/USD (score 9/28)\nRejected: Min cash reserve not met`
- `reason` is HTML-escaped via `html.escape()` before embedding in the Telegram HTML message

`src/agent/tools.py` — `TradingTools`:
- New `set_signal_scores(scores: dict)` method stores `{pair: score}` mapping in `self._signal_scores`
- `propose_buy()` extended: after `validate_buy()` returns a rejection reason, checks `score = self._signal_scores.get(pair, 0)`. If `score >= missed_signal_min_score` (config `signals.missed_signal_min_score`, default 8), calls `notifier.send_missed_signal(pair, score, max_score, reason)`
- `max_score` read from `config["signals"]["max_score"]` (28)

`src/agent/trading_agent.py` — `TradingAgent.run_cycle()`:
- Calls `self._tools.set_signal_scores({sig["pair"]: sig["score"] for sig in signals if sig["signal"] == "BUY"})` before dispatching to the LLM
- Ensures BUY signal scores are available in `TradingTools` for the duration of the cycle

**Config key added:** `signals.missed_signal_min_score: 8` — threshold below which rejections are silent.
