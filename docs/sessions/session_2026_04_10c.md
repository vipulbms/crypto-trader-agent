# Session Notes — 2026-04-10 (Part C)

## Changes

### 1. Fix: Total value in balance report shows stale audit snapshot

**Bug report:** After resetting `paper_trading.db` to a clean $1,000 slate, `kryptos.py report` showed `Total value: $979.99` while `Available: $1,000.00`. The gap matched the pre-reset state.

**Root cause:** `trade_report.get_portfolio_summary()` (line 95) set `total_usd = snap["total_usd"] if snap else cash`, reading from the last `audit_balance_snapshots` row in `audit.db`. Balance snapshots are only written during trading cycles, so the value is always stale between cycles — and completely wrong after a DB reset.

**Fix:** For paper mode, compute `total_usd` live: `cash + sum(usd_value of open positions)`. Only fall back to the audit snapshot for live mode (where cash must come from Kraken). The snapshot is still used for `snapshot_at` and `unrealised_pnl_usd`.

**Files changed:** `src/reports/trade_report.py` (lines 94–100)
