# Session Notes — 2026-04-11 (Part a)

## Changes

### 1. ADX trend strength filter added to signal scoring (#134)

**Feature request:** GH #134 — signal scorer had no way to distinguish trending vs ranging markets, causing false BUY entries during sideways/choppy conditions.

**Implementation:**
- `src/analysis/indicators.py`: Added `adx_period` config read; compute `ta.trend.ADXIndicator` (Wilder period=14). Returns `adx_14` in the indicators dict.
- `src/analysis/signals.py`: Read `adx_14`. In BUY scoring block: ADX > 40 → +1 (strong trend confirmed); ADX < 20 → −1 (ranging, soft penalty). ADX 20–40 = neutral (no change). Soft modifier only — not a hard veto.
- `config.yaml`: Added `indicators.adx_period: 14`; `signals.adx_trend_weight: 1`; `max_score` updated 16 → 22.
- `tests/test_adx_filter.py`: 4 Gherkin-style tests — penalty reduces score below threshold, boost fires BUY above threshold, neutral ADX has no effect, ADX < 20 is a soft penalty not a hard veto.

### 2. RSI divergence detection added to signal scoring (#135)

**Feature request:** GH #135 — system only looked at RSI level (oversold/overbought), ignoring price vs RSI momentum divergence, which is a high-probability reversal signal.

**Implementation:**
- `src/analysis/indicators.py`: Added `detect_rsi_divergence(prices, rsi_values, lookback)` standalone function. Uses split-half approach: divides lookback window into two halves, finds local extrema in each half, compares price and RSI directions. Returns `{bullish_regular, bearish_regular, hidden_bullish}`. Also returns `rsi_series` (last 30 values) and `close_series` (last 30 values) from `compute_indicators()` for use by signals.py.
- `src/analysis/signals.py`: Imports `detect_rsi_divergence`. Per-pair `rsi_divergence_lookback` read from `pair_cfg` → `sig_cfg` → default 20. Divergence computed from `rsi_series`/`close_series` in indicators dict. Scoring: bullish_regular +2 BUY, hidden_bullish +1 BUY, bearish_regular +2 SELL.
- `config.yaml`: Added `signals.rsi_divergence_bullish_weight: 2`, `rsi_divergence_hidden_bullish_weight: 1`, `rsi_divergence_bearish_weight: 2`, `rsi_divergence_lookback: 20`. Per-pair overrides: BTC/LTC=25 (slow movers), TRX/DOGE/HYPE=15 (fast/noisy).
- `tests/test_rsi_divergence.py`: 8 tests — 6 unit tests for `detect_rsi_divergence()` (each divergence type, no-divergence baseline, insufficient data, None values), 2 integration tests via `generate_signal()`.

### 3. Fast backtest (--no-llm) added to test_backtest.py

**Motivation:** Full LLM backtest takes ~2 hours for a 7-day window (672 cycles × ~11s LLM latency). Signal parameter changes (ADX thresholds, RSI divergence lookback, buy_min_score) only need signal-quality validation — LLM is not involved in score computation.

**Implementation:**
- `tests/test_backtest_fast.py`: Standalone fast backtest script. Replaces LLM with a deterministic rule engine: Signal=BUY + no open position + cash available → place_order; Signal=SELL + open position → close_position. Full mirror of production signal pipeline (adaptive ATR floor, BB squeeze, volume floor injections, regime caution). Prints per-pair table: Buys, TP, SL, Trailing Stop, Agent Sell, P&L USD, Win% with signal quality verdict.
- `tests/test_backtest.py`: Added `--no-llm` flag (delegates to `test_backtest_fast.run_backtest()`), `--pairs` filter flag. Keeps one unified entry point.

**Usage:**
```bash
~/.pyenv/versions/3.11.15/bin/python3 tests/test_backtest.py --no-llm --start-date 2025-12-25
~/.pyenv/versions/3.11.15/bin/python3 tests/test_backtest.py --no-llm --start-date 2025-12-25 --pairs BTC/USD ETH/USD
```
