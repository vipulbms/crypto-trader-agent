### 2. IFeedbackService interface extraction — enable Mockito mocking on Java 25

**Bug report:** `FeedbackControllerTest` and `AuthControllerTest` failed with 21 errors — Mockito Byte Buddy cannot instrument concrete classes on Java 25.0.2.

**Root cause:** `FeedbackService` is a concrete `@Service` class. On Java 25 Byte Buddy cannot instrument all classes in the type hierarchy. `AuthControllerTest` (`@SpringBootTest`) also failed because the Spring context couldn't create the `FeedbackService` bean (DataSourceAutoConfiguration excluded in test YAML).

**Fix:**
- Extracted `IFeedbackService` interface with `getRaa()` and `getAgents()` methods.
- Updated `FeedbackService` to `implements IFeedbackService`.
- Updated `FeedbackController` to inject `IFeedbackService` (not concrete class).
- Updated `FeedbackControllerTest` to `@Mock IFeedbackService`.
- Added `@MockBean FeedbackService` to `AuthControllerTest` to satisfy Spring context.

Files changed:
- `src/main/java/com/kryptos/api/feedback/IFeedbackService.java` (new)
- `src/main/java/com/kryptos/api/feedback/FeedbackController.java` (inject interface)
- `src/test/java/com/kryptos/api/feedback/FeedbackControllerTest.java` (mock interface)
- `src/test/java/com/kryptos/api/auth/AuthControllerTest.java` (add @MockBean)

### 3. Mockito mock-maker-inline for record mocking

**Bug report:** Existing tests that mock Java records (e.g. in `TradesV2ControllerTest`) would fail because records are final.

**Fix:** Created `src/test/resources/mockito-extensions/org.mockito.plugins.MockMaker` with content `mock-maker-inline`. This replaces the default Byte Buddy mock maker with the inline variant, which can handle final classes and records.
