# Session Notes — 2026-04-11 (Part R)

## Changes

### 1. Feat: Candlestick pattern signals — closes #184

**Feature request:** Issue #184 — add candlestick pattern detection as additive BUY score contributors: hammer (+1), bullish engulfing (+2), doji at BB lower band (+1). Additive bonuses only — never standalone signals.

**Design decision:** Global weights (not per-pair). Patterns use pure price ratios + ATR-normalised body size, so they are scale-adaptive across all pairs. Per-pair `buy_min_score` already gates entry sensitivity differences.

**Implementation:**

- **`src/analysis/indicators.py`**:
  - Added `detect_candlestick_patterns(opens, highs, lows, closes, atr)` at the end of the file.
  - Detection logic:
    - `hammer`: lower_wick > 2×body AND upper_wick < 0.3×body AND close > open (bullish body required)
    - `bullish_engulfing`: current close > prior open AND current open < prior close AND prior was bearish (prior close < prior open)
    - `doji_at_support`: body < 0.1 × ATR (scale-agnostic tiny body; "at support" gate applied in signals.py)
  - Called inside `compute_indicators()` try-block; result stored as `"candlestick_patterns"` in the return dict.
  - Passing all 4 OHLC series + current ATR to the function.

- **`src/analysis/signals.py`**:
  - Added 3 new entries to the score table docstring (Hammer +1, Bullish engulfing +2, Doji at BB lower +1).
  - Import extended: `detect_candlestick_patterns` added (was not needed at call site, but imported for explicitness).
  - Three new weight variables: `w_hammer`, `w_engulfing`, `w_doji_support` read from `sig_cfg`.
  - Scoring block added after BB squeeze release scoring (before SELL scoring):
    - Hammer and bullish engulfing fire purely from pattern detection.
    - Doji requires the pre-existing `near_lower` condition (price ≤ bb_lower × 1.005) as the "at support" gate.

- **`config.yaml`**:
  - Added to `signals:` section: `hammer_weight: 1`, `engulfing_weight: 2`, `doji_support_weight: 1`
  - `max_score: 25 → 28` (+3 from the three new contributors)

- **`tests/test_candlestick_patterns.py`** (new, 7 tests):
  - `test_hammer_detection` — unit: classic hammer OHLC → `hammer=True`
  - `test_bullish_engulfing_detection` — unit: engulfs prior bearish body → `bullish_engulfing=True`
  - `test_doji_detection` — unit: body < 0.1 × ATR → `doji_at_support=True`
  - `test_doji_not_detected_large_body` — unit: body > 0.1 × ATR → `doji_at_support=False`
  - `test_insufficient_candles_returns_false` — unit: <2 candles → all False (safe fallback)
  - `test_hammer_increases_buy_score` — integration via `generate_signal()`: hammer injected → "Hammer candle" appears in reasons
  - `test_doji_no_score_when_not_near_lower_bb` — integration via `generate_signal()`: doji detected but price far above BB lower → no doji reason awarded

**Test results:** 209 tests passing (202 baseline + 7 new).

## Known Behaviours Updated

- `candlestick_patterns` dict is always present in the indicators return dict. If fewer than 2 candles are available, all values are `False`.
- Doji scoring intentionally split: `detect_candlestick_patterns` only checks body size (< 10% ATR); the "at support" semantic is applied in `signals.py` via `and near_lower`. This keeps the detector pure.
- `max_score` is 28. Achievable maximum is theoretical — no single candle can trigger all signals simultaneously.
