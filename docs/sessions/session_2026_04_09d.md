# Session Notes — 2026-04-09 (Part D)

## Changes

### 1. Backtest clean-slate teardown fix (GH#122)

**Bug report:** Backtest run showed $7,300.57 portfolio value with 90 open positions from a $1,000 starting balance — physically impossible. Stale `paper_positions` from a prior run persisted into the new backtest.

**Root cause:** `test_backtest.py` teardown used a manually constructed `data_dir` path that could diverge from `get_connection()`'s path resolution in `database.py`. Additionally, there was no post-teardown validation — if the DB file was missing or deletion failed silently, the run would proceed with contaminated state.

**Fix:**
- `src/storage/database.py`: added `get_db_path()` public alias for `_get_db_path()` so callers outside the module can resolve DB paths using the same logic as `get_connection()`.
- `tests/test_backtest.py`:
  - Replaced manual `data_dir` construction with `get_db_path()` — teardown now uses identical path resolution to `get_connection()`.
  - After deletion, explicitly calls `init_paper_db()` and `init_audit_db()` to re-create a clean DB.
  - Validates pre-run state: asserts `COUNT(*) FROM paper_positions WHERE status='open' = 0` and `cash_usd == starting_balance`; aborts with a clear error message if contaminated.
  - Logs confirmed starting state: `Validated: 0 open positions, wallet=$1000.00`.

**Files changed:**
- `src/storage/database.py`
- `tests/test_backtest.py`
