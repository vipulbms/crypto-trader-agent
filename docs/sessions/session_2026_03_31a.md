# Session Notes — 2026-03-31 (Part A)

## Changes

### LLM Call INFO Logging

Added INFO-level logs for every LLM call: one log when the call is initiated, one when it completes (with latency in ms).

Previously only DEBUG logs existed inside the loop body — these remain unchanged.

| File | Log added |
|---|---|
| `src/agent/trading_agent.py` | Initiating call (pair + model) before attempt loop; Completed (pair, model, decision, latency_ms) after |
| `src/cli/nl_parser.py` | Initiating intent parse (model) before `client.chat`; Completed (model, latency_ms) after |
| `src/analysis/features.py` | Initiating post-trade analysis (pair + model) before `llm_client.chat`; Completed (pair, model, latency_ms) after |

Log format examples:
```
[LLM] Initiating call — pair=BTC/USD model=qwen3.5:27b
[LLM] Completed — pair=BTC/USD model=qwen3.5:27b decision=HOLD latency=3421ms

[LLM] Initiating intent parse — model=qwen3.5:27b
[LLM] Intent parse completed — model=qwen3.5:27b latency=812ms

[LLM] Initiating post-trade analysis — pair=ETH/USD model=qwen3.5:27b
[LLM] Post-trade analysis completed — pair=ETH/USD model=qwen3.5:27b latency=1204ms
```

### AVAX/USD Take-Profit Reduced

`config.yaml`: AVAX/USD `take_profit_pct` changed from `16` → `12`.

## Key Principle
All LLM call sites log at INFO level (visible in normal operation) on entry and exit.
Prompt/response content stays at DEBUG level (only written when `llm_debug_logging: true` in config).
