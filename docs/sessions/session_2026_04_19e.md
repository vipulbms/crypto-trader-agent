## Changes

### 1. S13.2.2 — Feed-frozen alert in notifier + main (from session D)
- `Notifier.send_feed_frozen_alert(pair, n_cycles)` sends Telegram ⚠️ FEED FROZEN alert

### 2. S13.2.3 — BTC/USD failover in features + main (from session D)
- `fetch_btc_spot_price(config)` in `src/analysis/features.py` — falls back to CoinGecko REST when WebSocket feed is FROZEN for BTC/USD
- `main.py` uses failover price in portfolio valuation when BTC feed is frozen
- Config: `qsa.btc_failover.enabled`, `qsa.btc_failover.min_freeze_cycles`

### 3. S13.3.1 — Volume bypass for momentum breakout
- `src/analysis/signals.py`: bypass block inserted between vol_blocked computation and `if vol_blocked: return`
- Bypass fires when all conditions true: `volume_bypass_enabled AND bb_upper is not None AND price > bb_upper AND macd_hist >= 0 AND macd_hist_prev < 0`
- Only for medium/high personas; conservative always blocked
- `main.py` injects `volume_bypass_enabled` from active persona config before `generate_signal()`
- Config: `personas.conservative.volume_bypass_enabled: false`, `medium: true`, `high: true`

### 4. S14.1.1 — Pipe-format signal blocks
- `src/agent/prompts.py`: `build_pipe_signal_block(signal, pair_tp_config, regime)` replaces verbose multi-line blocks
- Format: `pair|ETH/USD|score|7/28|direction|BUY|rsi|28|adx|35|macd_hist|0.1200|bb_pos|0.32|regime|bullish|price|1234.5600|tp_pct|12|sl_pct|5|max_buy_usd|200`
- Tier label removed from prompt (was "Tier 3 (speculative altcoin) | Max buy: $17.50"); `max_buy_usd` field carries the cap value
- `reasons` indented below the pipe line

### 5. S14.1.2 — Token budget trimming
- `estimate_tokens(prompt) -> int`: `len(prompt) // 4` fast estimator
- `build_cycle_prompt()` trims weakest BUY signals when estimated tokens > `max_prompt_tokens` (config: `llm.max_prompt_tokens: 3500`)
- Trimming log at INFO level: "[PROMPT] Trimmed N pairs to stay under token budget"

### 6. S14.2.1 — Current portfolio block

  `Total:$X  Cash:$Y  OpenPos:N  DailyPnL:+Z%  MaxPerTrade:$W`
- Open positions listed as sub-rows: `pos|pair|entry|curr|pnl_pct|tp_pct`
- `SYSTEM_PROMPT` updated: "Do NOT propose_buy for any pair listed in CURRENT PORTFOLIO."

### 7. S14.2.2 — Risk constraints block
- `build_cycle_prompt()` includes `## RISK CONSTRAINTS ##` pipe row when `risk_state` dict passed:
  `cash_usd|X|positions_open|N|positions_max|M|kill_switch|0|circuit_open|0|playbook|standard|persona|medium`

### 9. S21.1.1 — DataCollector standalone runtime
- NEW: `src/runtime/data_collector.py`
- Standalone asyncio process: subscribes to Kraken WS v2 ohlc + book channels
- `_ensure_schema(db_path)` — creates `candle_buffer` + `orderbook_snapshots` tables (also added to `COLLECTOR_SCHEMA` in `database.py`)
- `_upsert_candle()` — INSERT OR REPLACE into `candle_buffer` on `(pair, ts)`
- `_upsert_orderbook()` — INSERT into `orderbook_snapshots` with computed OBI
- `_backfill_pair()` — REST OHLC fetch on startup; INSERT OR IGNORE (preserves newer WS rows)
- `/health` HTTP endpoint (aiohttp): `{"status": "ok", "pairs_active": N, "last_write_ts": T}`
- CLI: `python -m src.runtime.data_collector --config config.yaml --db paper_trading.db`
- No dependency on `src/agent/` or `src/risk/` (shared-library pattern)
