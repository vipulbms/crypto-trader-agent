# Session Notes — 2026-04-01 (Part B)

## Changes

### 1. Switch LLM model to deepseek-r1:7b; fix timeout cascade

**Bug report / Feature request:** From midnight April 1, every single LLM cycle timed out. Agent was effectively frozen for 5+ hours. Fallback model (`llama3.1:8b`) was never installed, producing 404 errors with no recovery.

**Root cause / Motivation:**
- `qwen2.5:14b` (9 GB) was running on CPU — inference took 700–900 s per call, consuming the entire 900 s timeout on every cycle.
- Fallback model `llama3.1:8b` was not installed → 404 on every retry → silent failure.
- Even if fallback had worked, primary and fallback using same model = wasted 2× timeout (1200 s) on a single decision.

**Fix / Implementation:**
- `config.yaml`: `model` → `deepseek-r1:7b`, `fallback_model` → `deepseek-r1:7b` (user switched to deepseek-r1 after session; both primary and fallback set to same installed model), `timeout_seconds` 900 → 600.
- Note: deepseek-r1 emits `<think>…</think>` reasoning blocks. Ollama strips these before populating `msg.tool_calls`, so the agent's tool dispatch is unaffected.

### 3. KrakenClient live broker parity rewrite

**Bug report / Feature request:** Live mode (`--live`) was non-functional: `get_balance()` returned market value (not entry cost), `get_open_positions()` called `fetch_open_orders()` (open orders ≠ positions), `close_position()` and `check_stops_and_tp()` were missing entirely.

**Root cause / Motivation:** PaperBroker and KrakenClient had divergent interfaces — the rest of the system (main loop, tools, notifier) assumed they were interchangeable.

**Fix / Implementation:**
- `src/exchange/kraken_client.py` — complete rewrite:
  - `__init__`: added `live_db` param; stores `self._db = live_db`.
  - `get_balance()`: now mirrors PaperBroker — `total_usd = Kraken cash + Σ(usd_value of open DB positions)`. Uses entry cost, not market value.
  - `get_open_positions()`: queries `live_positions WHERE status='open'` from DB instead of `fetch_open_orders()`.
  - `get_open_positions_count()`: new method, counts open rows in DB.
  - `place_order()`: unchanged order placement logic + new DB INSERT into `live_positions` (entry/SL/TP order IDs stored).
  - `close_position()`: new method. If `exit_reason == "agent_sell"` → market sell + cancel SL + TP orders. If SL/TP → cancel counter-order only. Updates DB, inserts into `live_trades`, returns dict matching PaperBroker shape.
  - `check_stops_and_tp()`: new method. First fetches native SL/TP order status from Kraken (authoritative). Falls back to price-based check. Calls `close_position()` and `audit_logger.log_position_event()`.
- `main.py`:
  - Passes `live_db` from config to `KrakenClient.__init__`.
  - Removes `if mode == "paper":` guard from SL/TP loop — now runs for both paper and live mode.
