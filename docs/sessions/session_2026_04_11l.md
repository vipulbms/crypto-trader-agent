# Session Notes — 2026-04-11 (Part L)

## Changes

### 1. Fix: DB-persisted start-of-day balance — prevents false daily loss notification (#170)

**Bug report:** Running `reset_paper.py --yes` while `kryptos --paper` is alive triggers a false
40.6% daily loss notification, fires the global kill switch, and panic-sells all open positions.

**Root cause:** `start_of_day_bal = balance_data["total_usd"]` in `main.py` is captured once at
process start (line 145) and passed unchanged into every `run_cycle()` call. If `reset_paper.py`
wipes `paper_trading.db` while the agent is running, the DB resets to $1,000 but the in-memory
value (e.g. $1,685) is never refreshed. Next cycle: `get_daily_pnl(1685)` with `current_total=1000`
→ −40.6% → kill switch fires.

**Fix — `main.py`:**
- Added `_get_or_set_sod_balance(paper_db, current_balance)` helper.
  - Reads `agent_state` for key `start_of_day_balance_YYYY-MM-DD` (UTC date).
  - If found → return it (stable for the day).
  - If absent (new day or DB was reset) → store current balance and return it.
- At the start of each main loop iteration (paper + non-backtest mode only), calls this helper
  to refresh `start_of_day_bal` before passing it to `run_cycle()`.
- Self-healing: if `reset_paper.py` clears `agent_state`, the next cycle detects the missing key,
  writes the post-reset balance ($1,000), and uses that as the new daily baseline — no false alarm.
- Also handles midnight rollovers automatically (new date key each UTC day).

### 2. Fix: reset_paper.py running-agent guard (#171)

**Bug report:** No safeguard prevents `reset_paper.py` from running while the trading agent is live.

**Fix — `scripts/reset_paper.py`:**
- Added `--force` CLI flag.
- Added `_check_agent_running(paper_path)` helper: returns `True` if `paper_trading.db` was
  modified within the last 120 seconds (agent writes the DB every cycle).
- If the guard fires and `--force` is not passed: prints a prominent warning explaining the risk,
  tells the user to stop the agent first, and exits with code 1.
- Added `import time` to script imports.
