# Session 2026-05-21b — Fix: UnboundLocalError in build_cycle_prompt

## Issue
Agent cycle was crashing with:
```
UnboundLocalError: cannot access local variable 'usd_val' where it is not associated with a value
File /src/agent/prompts.py, line 292, in build_cycle_prompt
```

## Root Cause
`usd_val` was only defined inside the `if cur_price and entry:` conditional block (line 281), but used unconditionally at line 292 for the `pos_size_pct` calculation. When the condition was false (position without current_price), the variable was never assigned, causing UnboundLocalError.

## Fix
Move `usd_val = pos.get("usd_value", 0) or 0` initialization **before** the conditional block so it's always available.

- `src/agent/prompts.py` — Initialize `usd_val` before conditional (line 280)
