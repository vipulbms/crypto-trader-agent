### 2. Groq API Key Rotation (S26)
Files: `src/agent/trading_agent.py`

Cycles alternate between `GROQ_API_KEY` (primary) and `GROQ_API_KEY_2` (secondary):
- **Even cycles (0, 2, 4...)**: Primary key
- **Odd cycles (1, 3, 5...)**: Secondary key
- **Total quota**: 1M tokens/day (500k per key)
- **15-min cycles @ 3k tokens each**: 288k/day token usage (within budget)

Implementation:
- `TradingAgent.__init__()` stores both `_api_key_primary` and `_api_key_secondary`
- `_call_openai_compat()` rotates keys based on `cycle_id % 2`
- OpenAI client is recreated with selected key before each LLM call
- Logs rotation events: `[S26] Rotating to secondary Groq key (cycle N)`

### 3. Dynamic Cycle Interval (S26)
Files: `main.py`, `src/core/cycle_context.py`

**main.py changes:**
- Removed static `interval_s` calculation
- Each cycle reads `cycle_interval_minutes` from active persona config
- Falls back to global `trading.cycle_interval_minutes` if persona config is missing
- Logs selected persona and interval: `Cycle complete in X.Xs. Next cycle in Y.0s (persona=high, interval=15min).`

**cycle_context.py additions:**
- New helper `get_active_persona_from_db(db_path)` reads `active_persona_override` from `agent_state` table
- Supports Java API persona override (S18.1.3) without agent restart
