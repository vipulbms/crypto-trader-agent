# Session Notes — 2026-05-18

## Changes

### 1. MCP Server Signal Introspection Tools

**Motivation:** Operational observability for the MCP query interface. Dashboard and external tools need visibility into signal scoring details and open-position reasoning.

**Implementation:** 
- `src/mcp/server.py`: Added two new query tools:
  - `tool_get_signal_reasons()` — returns latest signal per pair with direction, strength, reasons, and indicator snapshots (RSI, MACD, BB mid, ATR, price)
  - `tool_get_open_position_reasons()` — same format but filtered to only open-position pairs
  - Helper `_latest_signal_reasons()` fetches audit_signals with per-pair MAX(id) subquery
  - Helper `_open_position_pairs()` returns set of pairs with open status
  - Improved PYTHONPATH handling via `sys.path.insert(0, ROOT_DIR)` to allow running as script
- `mcp.json`: New MCP server configuration file declaring all 8 tools (now up from 6)
- Docstring updated: "Provides **seven** read-only tools" → "Provides **eight** read-only tools" (accounting for `get_signal_snapshot` and now two signal reason tools)

### 2. Multi-Agent Orchestration Script

**Motivation:** Operational runbook for starting the core trading agent plus all auxiliary services (ResearchAnalyst, AuditAgent, DataCollector, FulfillmentService, MCP server).

**Implementation:**
- `scripts/start_all_agents.sh`: New orchestration script
  - Parses `config.yaml` for log directory (auto-creates it)
  - Starts trading agent via `kryptos.py start --paper`
  - Launches auxiliary runtimes in `nohup` background: DataCollector, ResearchAnalyst, AuditAgent, FulfillmentService, MCP server
  - Logs each service to dedicated file in configured log_dir
  - Prints helpful output showing log directory and PID file location
