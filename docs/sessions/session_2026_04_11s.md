# Session Notes — 11 April 2026 (Part S)

## Changes

### 1. Add PENDLE/USD trading pair (Closes #186)

**Feature request:** Add Pendle Finance (DeFi yield protocol) as a new active trading pair.

**Motivation:** PENDLE has expiry-driven yield cycle dynamics that create predictable short-term momentum windows. Clear trending phases with BB squeeze releases. Low correlation with BTC momentum. Sufficient Kraken liquidity (Tier 1).

**Implementation:**
- `config.yaml`: Added full 16-field pair block (TP 20%, SL 5%, `buy_min_score=7`, `caution_factor_bearish=0.40`)
- `config.yaml` `trailing_stop.per_pair_overrides`: Added `PENDLE/USD` with `trail_pct: 7.0`, `activate_after_pct: 5.0` (spike-and-retrace profile, same as DOGE)
- `config.yaml` `risk.correlation_clusters`: Added `PENDLE/USD` to `eth_ecosystem` cluster (alongside OP/ARB/UNI)
- `history/PENDLEUSD_candle.json`: 721 15-min candles fetched from Kraken REST API
- Params: `atr_tp_min_pct=0.35`, `rsi_oversold=28`, `rsi_overbought=74`, `bb_squeeze_threshold_pct=2.0`, `min_volume_ratio=0.40`, `obv_noise_threshold=0.010`, `rsi_divergence_lookback=15`, `obv_trend_period=7`

### 2. Add ONDO/USD trading pair (Closes #187)

**Feature request:** Add Ondo Finance (RWA tokenisation protocol) as a new active trading pair.

**Motivation:** ONDO price is partly driven by TradFi interest rate expectations (Treasury yield curve) rather than pure BTC momentum — portfolio diversification benefit. Steady trending profile with extended ADX phases. RSI divergence detection particularly effective.

**Implementation:**
- `config.yaml`: Added full 16-field pair block (TP 16%, SL 5%, `buy_min_score=6`, `caution_factor_bearish=0.50`)
- No trailing stop override (standard global 5%/3% applies)
- Unclustered (independent RWA price drivers)
- `history/ONDOUSD_candle.json`: 721 15-min candles fetched from Kraken REST API
- Params: `atr_tp_min_pct=0.28`, `rsi_oversold=28`, `rsi_overbought=70`, `bb_squeeze_threshold_pct=1.8`, `min_volume_ratio=0.35`, `obv_noise_threshold=0.005`, `rsi_divergence_lookback=20`, `obv_trend_period=10`

### 3. Add BONK/USD trading pair (Closes #188)

**Feature request:** Add BONK (largest Solana-native memecoin) as a new active trading pair.

**Motivation:** BONK exhibits extreme parabolic spikes during Solana ecosystem bull runs. BB squeeze release fires reliably before BONK breakouts. OBV accumulation patterns visible with 7-period lookback. `buy_min_score=9` ensures only maximum confluence entries are taken.

- `config.yaml` `risk.correlation_clusters`: Added `BONK/USD` to `memecoins` cluster (alongside DOGE/HYPE/WIF/PEPE)
- `history/BONKUSD_candle.json`: 721 15-min candles fetched from Kraken REST API
- Params: `atr_tp_min_pct=0.50`, `rsi_oversold=28`, `rsi_overbought=72`, `bb_squeeze_threshold_pct=2.5`, `min_volume_ratio=0.50`, `obv_noise_threshold=0.020`, `rsi_divergence_lookback=15`, `obv_trend_period=7`
