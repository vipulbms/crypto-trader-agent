# Session Notes — 8 April 2026 (Part A)

## Changes

### 1. Integrate `daily_report.py` and `review.py` into `src/reports/` and Kryptos CLI

**Feature request:** Move the report logic from `scripts/daily_report.py` and `scripts/review.py` into the `src/reports/` package so they can be invoked directly from the `kryptos.py` CLI without running standalone scripts.

**Motivation:** The two scripts contained significant business logic that was unreachable from the interactive CLI or NL parser. Moving them into `src/reports/` makes them first-class, testable modules with a single source of truth. The standalone scripts remain as thin entry-point wrappers for cron/launchd use.

**Implementation:**

- **New `src/reports/daily_report.py`:** Core `run_daily_report(mode, day_offset, config=None)` function extracted from the old script. Accepts an optional pre-loaded `config` dict (loaded from disk if `None`). Produces the full daily P&L report: balance delta, trades, per-pair all-time stats, decision cycle counts, error count.

- **New `src/reports/review_report.py`:** Core `run_review(mode, days, config=None)` function extracted from the old script. Produces the N-day performance review: balance return, trade stats (win rate, SL/TP/agent-sell breakdown), max drawdown, per-pair breakdown, LLM behaviour summary, top HOLD reasons, full trade log, and the **READY FOR LIVE TRADING?** verdict.

- **`scripts/daily_report.py` (thin wrapper):** Reduced to `argparse` + `from src.reports.daily_report import run_daily_report`. Standalone usage unchanged.

- **`scripts/review.py` (thin wrapper):** Reduced to `argparse` + `from src.reports.review_report import run_review`. Standalone usage unchanged.

- **`src/cli/commands.py`:** Added `cmd_daily_report(params, config)` and `cmd_review(params, config)`. Both registered in `dispatch_map` under `"daily_report"` and `"review"`.

- **`src/cli/nl_parser.py`:** Added `daily_report` and `review` to `INTENTS`. Added `days_ago` parameter to the NL system prompt and JSON response schema.

- **`kryptos.py`:** Added `daily` and `review` subcommands to `build_arg_parser()`. `daily` accepts `--days-ago` and `--mode`. `review` accepts `--days` and `--mode`. Both added to `run_direct()` mapping. Docstring and argparse epilog examples updated.

**New CLI usage:**
```bash
python kryptos.py daily                    # Today's full daily P&L report
python kryptos.py daily --days-ago 1       # Yesterday's report
python kryptos.py review                   # 14-day review with verdict
python kryptos.py review --days 30 --mode live
```
