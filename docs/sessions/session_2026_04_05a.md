# Session Notes — 5 April 2026 (Part A)

## Changes

### 1. Minimum Profit Floor

**Bug report / Feature request:** Implement the "Minimum Profit Floor" to avoid losing money to Kraken fees.

**Root cause / Motivation:** Kraken imposes Maker/Taker fees which average `0.60%` for a round trip + slippage. Exiting a trade at +0.50% yields a net loss in USD.

**Fix / Implementation:**
- Converted `min_profit_floor_pct: 1.0` to a configurable parameter in `config.yaml`.
- Extracted hardcoded constraints to a newly created `.claude/skills/trading-rules/SKILL.md` skill file.
- `TradingAgent` in `src/agent/prompts.py` now loads system instructions dynamically from `SKILL.md`.
- Added mathematical profit floor validation to `src/risk/risk_manager.py -> validate_sell`.
- Updated `src/agent/tools.py -> propose_sell` to pass live execution price to `validate_sell`.
