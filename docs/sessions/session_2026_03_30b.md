### 1. BNB Early Exit Investigation
- BNB was sold by the LLM via `propose_sell` (Feature 6 exit timing alert) — not by SL/TP
- Entry: $609.36 | Exit: $610.09 | P&L: -0.14% | Reason: agent_sell
- **Bug**: LLM treated exit timing alerts as action commands instead of information
- **Fix** (`src/agent/prompts.py`): Added `EXIT MANAGEMENT` section to SYSTEM_PROMPT
  - SL/TP owns all exits — LLM must not call propose_sell on stalled positions
  - Exit timing context is INFORMATIONAL only
  - Only call propose_sell on open position if Signal=SELL AND clear momentum reversal

### 6. Pair Map Externalisation (major refactor)
**Before**: `PAIR_MAP`, `REST_PAIR_MAP`, `KRAKEN_PAIR_MAP` hardcoded in Python files

**After**: Single source of truth in `config.yaml` — each pair entry now has:
```yaml
- pair: BTC/USD
  ws_name: XBT/USD      # Kraken WebSocket v2 symbol
  rest_name: XBTUSD     # Kraken public REST OHLC symbol
  take_profit_pct: 8
  stop_loss_pct: 5
```

Changes:
- `src/exchange/websocket_feed.py`: `_build_pair_maps(config)` reads from config; instance attrs `self._pair_map` / `self._rest_pair_map`

- Adding a new pair now only requires editing `config.yaml`

### 7. Websocket Backfill Bug Fix
- **Bug**: `result.get(rest_pair)` failed because Kraken returns internal key (`XXBTZUSD` for BTC, `XDGZUSD` for DOGE) — different from the REST name sent
- **Fix** (`src/exchange/websocket_feed.py`):
  ```python
  result_key = next((k for k in result if k != "last"), None)
  candles_raw = result.get(result_key, []) if result_key else []
  ```

3. Exit timing alerts = informational only
