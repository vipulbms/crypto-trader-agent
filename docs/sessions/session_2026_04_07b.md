# Session Notes — 2026-04-07 (Part B)

## Changes

### 1. Chore: Migrate Claude Memory Files to Project Scope (closes #91)

**Feature request:** Memory files were in user-scoped `~/.claude/projects/.../memory/` — not in git, not available to other contributors or on other machines.

**Motivation:** All conventions, feedback rules, and project context should be available to any contributor (or Claude session on any machine) without manual setup. Claude Code auto-loads files imported via `@` directives in `CLAUDE.md`.

**Implementation:**
- Created `.claude/memory/` directory in the repo with 4 files:
  - `project_kryptos.md` — architecture, pairs, critical conventions, config values, gotchas
  - `feedback_coding_style.md` — response style, commit workflow, proactive fixes, log diagnosis
  - `feedback_testing.md` — tests/ folder, Gherkin docstrings, standalone runnable
  - `feedback_github_traceability.md` — GitHub issue required before every change (What/Why/How)
- Added `@.claude/memory/*.md` import directives at the top of `CLAUDE.md` so Claude auto-loads them on every session
- Updated user-scoped `MEMORY.md` with a migration notice pointing to the project files as source of truth
