### 1. Add 10 new trading pairs (closes #145–#154)

**Feature request:** GitHub issues #145–#154 each specified one new trading pair to onboard to Kryptos with suggested parameters, caution factor, and trailing-stop overrides.

**Motivation:** Expand the universe of tradeable assets from 14 active pairs to 24, covering Solana meme (WIF, JUP), Telegram chain (TON), Ethereum L2s (OP, ARB), meme extremes (PEPE), modular blockchain (TIA), AI/GPU compute (RENDER, FET), and Bitcoin L2 (STX).

**Implementation:**

All steps followed the `add-pair` skill methodology:

1. **Kraken API verification** — confirmed REST/WS names for all 10 pairs via `/AssetPairs` endpoint:

   - STX/USD → `STXUSD` / `STX/USD`

2. **Historical candle fetch** — 721 candles (15-min interval, ~7.5 days) fetched for all 10 pairs via Kraken OHLC REST endpoint and saved to `history/*USD_candle.json`.

3. **Calibration** — `scripts/calibrate_params.py` run per pair. Due to Kraken's 721-candle API limit, bb_squeeze values were unreliable (many at 0.0%). RSI percentiles used where sensible; issue spec values used for atr_tp_min_pct and bb thresholds.
