# Session Notes — 2026-04-07 (Part C)

## Changes

### 1. Fix: HistoricalFeed Timestamp-Based Price Lookup

**Bug report:** 3 open positions in the backtest (BNB/USD, AVAX/USD, UNI/USD) were never closed after 841 cycles (~17.5 days). Backtest ended with all 3 still open at exactly their entry prices.

**Root cause:** `HistoricalFeed` used a single global `_position` counter shared across all pairs. When fetching a candle for a shorter pair, the code clamped the index:
```python
pos = min(self._position, len(candles) - 1)
```
BTC/USD has ~429,034 candles; BNB/USD has only ~24,328. When `_position` exceeded 24,327, BNB always returned its last candle (Dec 2025) regardless of how far the backtest had progressed. The price was permanently frozen at the entry price — meaning neither the 5% stop-loss nor the TP level was ever crossed.

**Fix:** Full rewrite of `src/exchange/historical_feed.py`:
- Added a `_ref_pair` (the pair with the most candles) whose candle sequence defines the reference timeline
- Introduced `_current_ts` — the timestamp of the current reference candle
- Pre-computed sorted timestamp arrays (`_pair_times`) for all pairs using `bisect` for O(log n) lookup
- `_pair_pos(pair)` uses `bisect.bisect_right` to find the index of the last candle for that pair whose `time <= _current_ts`
- `get_candles()` and `get_latest_price()` both route through `_pair_pos()`; shorter pairs return `None` / `[]` when the backtest hasn't reached their history yet (guarded by `is_ready()` in the main loop)
- `start_date` warm-up logic preserved: searches the reference pair's timestamp list via `bisect_left` and steps back `min_candles` positions

**Files changed:**
- `src/exchange/historical_feed.py` — complete rewrite

**Tests:** All 51 pass after the fix (`pytest tests/ -v` → 51 passed in 8.34s).
