# Session Notes — 2026-04-18 (Part G)

## Changes

### 1. Add RAVE/USD trading pair; reject SAROS/USD (illiquid)

**Feature request:** Add SAROS/USD and RAVE/USD to the Kryptos trading agent.

**Motivation:** Expand pair coverage with new tokens available on Kraken.

**SAROS/USD rejection:** SAROS/USD exists on Kraken (REST: SAROSUSD, WS: SAROS/USD, price ~$0.000666) but is essentially dead — out of 721 fetched 15-min candles, nearly all had 0 trades and 0 volume. The agent's volume dead-zone guard would block every buy signal. Pair was rejected at the liquidity screening stage.

**RAVE/USD implementation:**

RAVE is a high-volatility NFT/DeFi token (~$27) with active liquidity (100–200 trades/candle), large HL swings (p75 HL 4.17% per 15-min candle), and clean RSI cycles.

**Signal parameters calibrated from 723 candles (2025-01-01 to 2026-04-18):**
- `atr_tp_min_pct`: 1.52 (p25 ATR 1.90% × 0.8)
- `rsi_oversold`: 36 (RSI p5=38, data-backed)
- `rsi_overbought`: 80 (RSI p95=81.8, capped at 80)
- `bb_squeeze_threshold_pct`: 7.85 (p10 BB width — pair rarely squeezes)
- `min_volume_ratio`: 0.40 (dead zone at 0.40 threshold is only 2%)
- `caution_factor_bearish`: 0.40 (high-vol speculative — same as HYPE/MOVR)
- `buy_min_score`: 7 (new pair, no track record — strong confluence required)
- `rsi_divergence_lookback`: 15, `obv_trend_period`: 7 (fast cycles, high-vol)
- `obv_noise_threshold`: 0.020 (2% floor, same as DOGE/HYPE)
- `slippage_pct`: 0.20 (thinner book alt, Tier 3)
- `pair_tier`: 3 (speculative altcoin)

**Trailing stop:** 7%/5% (meme/high-vol tier — wide trailing room)

**Correlation cluster:** unclustered (standalone NFT/DeFi price driver)

**7-day fast backtest result:** 21 buys, 60% win rate — parameters validated.
