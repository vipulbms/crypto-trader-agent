### 2. Fix: Trailing Stop Too Aggressive — Backtest Loss Analysis (closes #102, #103, #104)

**Bug report:** 658-cycle backtest (Jul 1–5 2025) analysis: 5 of 8 closed trades were losses. Root causes identified and fixed.

**Root causes and fixes:**

**[#102] Trailing stop activates too early (SOL -0.37%, AVAX -1.04%):**
- `activate_after_pct: 1.5` fired after 1.5% gain, moving SL from 5% to ~1% below entry. Any 2% consolidation stopped the trade out.
- Fix: raised global `trail_pct` 3→5%, `activate_after_pct` 1.5→3.0%
- `per_pair_overrides` changed from scalar floats to dicts `{trail_pct, activate_after_pct}`: DOGE/RAILS/HYPE trail=7%/activate=5%, SUI trail=6%/activate=4%
- `paper_broker.py` and `kraken_client.py` updated to read dict format (backward-compatible with scalar)
- 3 new tests in `tests/test_trailing_stop.py`

**[#103] ATR floor too low — entries in compressed markets:**
- `atr_tp_min_pct: 0.3%` allowed DOGE/UNI/INJ entries when ATR was 0.39% — expected move 0.58%, SL risk 5% (16× the edge)
- Fix: raised `atr_tp_min_pct` 0.3→1.0% in `config.yaml`. No code change.

**[#104] BB width scaling never implemented:**
- `bb_width_scale: true` in config but `compute_dynamic_tp()` never used BB width
- Fix: added squeeze guard in `src/analysis/features.py:compute_dynamic_tp()` — when BB width < `squeeze_threshold_pct` (1.0%), TP clamps to pair floor
- 2 new tests in `tests/test_regime_and_dynamic_tp.py`

**All 59 tests pass** (1 pre-existing import error: `test_chart_generator` needs pytest).

### 3. Fix: Dynamic TP Respects Pair-Level Configured Minimum (closes #95)

**Bug report:** DOGE/RAILS/HYPE stored TP=5% in DB despite config specifying 20%. Dynamic TP was using global `min_tp_pct: 5` floor for all pairs, ignoring per-pair static TP.

**Fix:** `src/analysis/features.py:compute_dynamic_tp()` — `min_tp = max(global_min_tp, pair_static_tp)`. ATR can push above pair TP but never below it.
