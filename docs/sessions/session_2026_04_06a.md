### 1. Backtest Analysis — Root Cause Diagnosis

**Bug report / Feature request:** User wanted to know why all gains were capped at 2-4% despite TP targets of 5-20%.

**Root cause:** Two structural problems identified from 3,931-cycle backtest (Apr 5–6, 16 hours):
1. `validate_sell()` in `src/risk/risk_manager.py:339` only enforces a 1% minimum floor — no upper-side proximity guard. The BRD FR-20 rule ("must be ≥ 80% of TP target before early exit") exists only as a prompt instruction in `SKILL.md`, not as code enforcement.
2. Only LTC/USD generated BUY signals in the entire run — 14/15 pairs returned HOLD due to confluence score < 5 on historical data.

**Backtest results table:**
| Exit Reason | Count | Total P&L |
|---|---|---|
| agent_sell | 14 | +$56.94 (avg +$4.07) |
| take_profit | 2 | +$28.10 (avg +$14.05) |
| stop_loss | 6 | -$96.24 (avg -$16.04) |

All 14 `agent_sell` exits showed identical LLM reason: "RSI overbought and price near upper Bollinger Band with SELL signal, P&L above profit floor."

### 2. GitHub Issues Shell Script — Epic E12 + All Epics

**Feature request:** Create a comprehensive shell script to generate all GitHub epics and stories as issues with full AC and traceability.

**Implementation:** `scripts/create_github_issues.sh`
- Covers Epics E1–E12 (E1–E11 from `docs/epics_stories_ac.md` + E12 new)
- 28 story issues total across 12 epics
- Uses `gh issue create` + GitHub sub-issues API (`POST /repos/{owner}/{repo}/issues/{num}/sub_issues`) to register stories as sub-issues of their parent epic
- Gracefully falls back if the sub-issues API is unavailable
- Each story body includes: traceability to Epic #NUM, BRD FR-XX, DSD §X.X, NFR-XX, exact code file::function

**E12 — Stop-Loss Protection & Gain Preservation (new):**
- S12.1.1: Bug fix — enforce 80% TP proximity in `validate_sell()` before LLM can `propose_sell`
- S12.2.1: Trailing stop — move SL upward as price rises, tracks `highest_price_seen`
- S12.3.1: Breakeven stop — one-time SL jump to entry at configurable profit threshold (mutually exclusive with trailing stop)
- S12.4.1: ATR-based SL — volatility-proportional SL at entry, bounded by `[min_stop_loss_pct, 5%]`
- S12.5.1: Partial take-profit — close 50% at 50% of TP target, optionally move remaining SL to breakeven
