# Session Notes — 2026-05-03 (Part B)

## Changes

### 1. RAA batch LLM evaluation — all candidates in one call (#357)

**Feature request:** Issue #357 — eliminate per-pair LLM call loop; evaluate all candidates in a single conversation so the model can compare them relatively.

**Motivation:** The previous approach called the LLM once per candidate, each with full data-fetch tool rounds. This triggered Groq rate limits and prevented cross-candidate ranking.

**Implementation:**

- `src/runtime/research_analyst.py`:
  - Replaced `_run_llm_universe_decision(pair, ...)` with two focused functions:
    - `_apply_llm_decision(decision_args, universe, db_path, ticker_data)` — applies a single `universe_decision` tool call result, enforces HITL lock + meme-block hard guards, commits to DB.
    - `_run_llm_batch_universe_decision(candidates, universe, db_path, config, ai_client, ticker_data, persistence_data)` — runs a single LLM conversation covering all candidates; ticker and persistence data pre-injected into the user message so no data-fetch tools are needed; collects all `universe_decision` calls in one tool loop; any skipped candidate gets a synthetic HOLD + `LLM_NO_DECISION` audit row.
  - Added `_RAA_BATCH_TOOLS` (decision tool only) — eliminates data-fetching tool round-trips that trigger rate limits.
  - Updated `_build_raa_system_prompt()` — reworded for batch: "evaluate ALL candidates listed in this cycle", "call universe_decision ONCE per candidate", "all data is pre-injected".
  - Added logging infrastructure: `init_llm_logger` + `log_llm_interaction` wired at startup; `init_cycle_logger` + `write_raa_cycle_report` called after each cycle; module-level `_RAA_SESSION_ID` + `_raa_cycle_counter`; `RotatingFileHandler` on `agent.log` (TTY-aware `StreamHandler`).

- `src/utils/cycle_logger.py`:
  - Added `write_raa_cycle_report(cycle_id, duration_ms, candidates, decisions, persistence_data, persona)` — appends a JSON record with `source=RAA` to `cycle_decisions.log`; includes per-candidate action/reason/ps/cycles/classification rows + summary counts (n_add/n_hold/n_remove/n_no_decision).

- `config.yaml`: `agent.persona` set to `high`; `agent.concurrent_mode` set to `true`.
