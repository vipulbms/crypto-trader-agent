# Session Notes — 2026-04-06 (Part C)

## Changes

### 1. Fix: ATR Floor Decoupled from Fee Floor — Multi-Pair Signal Coverage

**Bug report / Feature request:** 14 of 15 trading pairs generated zero BUY signals during a 5,217-cycle backtest. Only LTC/USD traded.

**Root cause:** `signals.py:119` used `min_profit_floor_pct: 1.0` as the ATR floor gate. For large-cap pairs with lower absolute ATR (BTC ATR ~$250 / $80k price = 0.625%), this blocked all BUY signals. The 1% fee floor is correct for `validate_sell()` but is too strict as a signal quality gate.

**Fix:**
- Added `atr_tp_min_pct: 0.3` to `config.yaml` under `dynamic_tp:` block
- `src/analysis/signals.py:119` now reads `config.get("dynamic_tp", {}).get("atr_tp_min_pct", ...)` with fallback to `min_profit_floor_pct` for backward compatibility
- BTC (0.625%), ETH (~0.8%), SOL (~1.0%) will now pass the ATR gate and generate BUY signals when RSI/MACD/BB conditions align

---

### 2. Fix: RSI Overbought Threshold Raised — Reduce Premature SELL Signals

**Bug report / Feature request:** LLM was triggering SELL signals too early (at RSI > 60), contributing to `agent_sell` exits well before TP targets.

**Root cause:** `config.yaml indicators.rsi_overbought: 60` is too low. RSI of 60 is only mildly elevated — traditional overbought is 70+.

**Fix:** Raised `rsi_overbought` from 60 to 65 in `config.yaml:126`.

---

### 3. Fix: validate_sell() TP Proximity Guard — Code-Enforce BRD FR-20

**Bug report / Feature request:** 18/27 backtest trades exited via `agent_sell` at avg +4.12% despite TP targets of 5–20%. BRD FR-20 requires ≥80% TP proximity before early exit, but this was prompt-only — not code-enforced.

**Root cause:** `validate_sell()` in `src/risk/risk_manager.py:339` only checked a 1% minimum floor. No upper-side guard existed.

**Fix:**
- Added `early_sell_min_tp_proximity_pct: 80` to `config.yaml` under `trading:`
- Added `self._early_sell_min_tp_proximity_pct` to `RiskManager.__init__()`
- Added proximity guard after the floor check in `validate_sell()`:
  - Reads `take_profit_pct` from the open position dict (already stored in `paper_positions`)
  - Computes `proximity_threshold_pct = take_profit_pct × (80 / 100)`
  - Rejects sell with `"Early Exit Guard: P&L +X.XX% is below Y.Y% ..."` if P&L < threshold
  - Automatic SL/TP exits (via `check_stops_and_tp()`) bypass `validate_sell()` — unaffected
- Updated `.claude/skills/trading-rules/SKILL.md` to note the 80% rule is now code-enforced
- Added 5 unit tests to `tests/test_risk_manager.py` (all pass):
  - Sell blocked at 50% of TP (+5% when TP=12%)
  - Sell allowed at 85% of TP (+10.2% when TP=12%)
  - Sell allowed above 100% of TP (+13% when TP=12%)
  - Floor check fires before proximity guard (+0.5%)
  - Graceful fallback when `take_profit_pct` missing from position dict
