# Session 2026-04-13a — Fix: isolate test_circuit_breaker + test_correlation_guard from production DB

## GitHub Issue
[#234](https://github.com/vipulbms/crypto-trader-agent/issues/234) — Bug: test DB files hardcode production paper_trading.db path, wiping live positions

## Root Cause
`tests/test_circuit_breaker.py` (line 19) and `tests/test_correlation_guard.py` (line 17) both hardcoded:
```python
DB_PATH = "paper_trading.db"
```
`get_connection("paper_trading.db")` → `_get_db_path()` → `data/paper_trading.db` (production DB).

`test_correlation_guard.py`'s `_seed_positions()` function called:
```python
conn.execute("DELETE FROM paper_positions WHERE pair LIKE '%/USD'")
```
...which wiped all live open positions from the production paper trading database while the agent was sleeping between cycles.

## Incident Timeline
- **14:02** — Cycle 304: 6 open positions, balance ~$999
- **Between 14:02 and 14:17** — Tests ran (likely `pytest` or similar); `_seed_positions()` deleted all `/USD` positions
- **14:17** — Cycle 305 woke up: `get_balance()` = cash + 0 positions = $397.83; SOD was $1,000; daily PnL = -60.2% → kill switch fired

This was a false positive. The actual portfolio was worth ~$999 — the positions were deleted in-process, not lost to the market.

## Evidence
- `sqlite_sequence`: `paper_positions=236`, `paper_trades=814` — rows were inserted then deleted
- `audit_cycles`: Cycle 304 showed 3 open positions with balance $998.96; Cycle 305 showed 0 open positions with balance $397.83
- `audit_position_events`: 6 `opened` events, 0 close events for those positions

## Fix
Changed both files to use the UUID temp-DB pattern already established in `test_sod_balance.py`:
```python
import uuid
DB_PATH = f"test_paper_{uuid.uuid4().hex[:8]}.db"
```
Also updated `DB_TIERED` in `test_circuit_breaker.py` from the fixed name `"test_paper_cb_graduated.db"` to a UUID-based name for full isolation.

## Files Changed
- `tests/test_circuit_breaker.py` — added `import uuid`; changed `DB_PATH` and `DB_TIERED` to UUID names
- `tests/test_correlation_guard.py` — added `import uuid`; changed `DB_PATH` to UUID name

## Tests
280 passed (no regressions). The two affected test files pass cleanly.
