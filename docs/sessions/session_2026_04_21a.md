### 5. S19.1.1 AC2+AC4 — Per-persona fast backtest CSV output and `--all-personas` flag

**Feature request:** AC2 required CSV export with a `persona` column; AC4 required an `--all-personas` flag that runs all three personas sequentially.

**Implementation** (`tests/test_backtest.py`):
- Added `csv` and `copy` imports.
- Added `ALL_PERSONAS_ORDER = ["conservative", "medium", "high"]` and `_TRADE_COLUMNS` constant listing all 17 trade columns including `persona`.
- `_read_trades_from_fast_db(persona_label)` — queries `paper_trades` from `backtest_fast_paper.db`, returns rows with `persona` field set to the given label.
- `_write_csv(trades, output_path)` — writes `csv.DictWriter` output using `_TRADE_COLUMNS`.
- `_print_persona_comparison(results)` — prints aligned comparison table (Start $, End $, Net P&L, Net%, Cycles, Buys) across all three personas.
- New argparse flags: `--all-personas` (store_true), `--csv` (store_true), `--output` (default `"backtest_results.csv"`).
- All-personas loop: `deepcopy` config per persona → `apply_persona` → `run_backtest` → collect results; finally calls `_print_persona_comparison` and optionally `_write_csv`.

**File:** `tests/test_backtest.py`

### 6. S19.1.2 AC1+AC2 — Conservative persona vs v2 baseline regression test

**Feature request:** AC1/AC2 required a regression test comparing the conservative persona run against the no-persona (v2 baseline) run, with tolerance checks on key metrics.

**Implementation** (`tests/test_persona_regression.py`):
- Added `_run_mini_backtest_no_persona(max_steps)` — runs BTC+ETH fast backtest without calling `apply_persona()` (v2 baseline).
- Added `TestConservativeVsV2Baseline` class (skipped unless `history/` candle files present — CI-safe):
  - `test_both_runs_complete` — validates both runs return valid structure with `cycles ≥ 1`.
  - `test_conservative_final_balance_within_tolerance` — asserts final balance difference is within 0.1% of starting balance; catches persona config override bugs.
  - `test_cycle_counts_match` — both runs iterate the same number of candle cycles.
  - `test_starting_balance_unchanged` — both runs start from the same balance (no startup side-effect from persona application).

**File:** `tests/test_persona_regression.py`
