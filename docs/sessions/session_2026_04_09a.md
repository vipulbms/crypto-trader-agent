# Session Notes — 2026-04-09 (Part A)

## Changes

### 1. Analysis: Rolling-Window Parameter Stability & Buy/Sell Signal Assessment

**Feature request:** Full statistical assessment of all signal parameters from 2025-01-01 data to identify what is globally miscalibrated and what should be per-pair.

**Motivation:** Backtest running but generating 0 trades — traced to `atr_tp_min_pct: 1.0%` blocking 93–99.8% of all signals across every pair. Prompted full analysis.

**Analysis performed:**
- `scripts/analyse_atr_profile.py` — ATR% distribution per pair (min/p10/p25/median/p75/p90/max)
- `scripts/analyse_pair_params.py` — RSI, MACD, BB, volume statistics per pair from 2025-01-01
- `scripts/analyse_rolling_windows.py` — rolling window stability (CV) for ATR/BB/volume adaptive parameters at window sizes 50/100/200/400; buy/sell signal win rates; blocked signal analysis

**Key findings:**
- `atr_tp_min_pct: 1.0%` blocks 93–99.8% of signals; blocked signals win at same rate as unblocked (zero alpha)
- All adaptive parameters (ATR floor, BB squeeze, volume floor) never stabilise (CV < 0.20) at any window size — 400 candles is the least-unstable
- Buy signal win rates: INJ 53.8%, SUI 50.7%, AVAX 49.5%; BTC 22.1%, TRX 18.9% (too low to be profitable)
- MACD decay threshold `-0.0005` fires 0% of the time for TRX, 0.3% for DOGE — broken for low-price pairs
- Volume dead zone blocks 57–58% of BNB/UNI/INJ candles — majority of their history classified as dead zone

**Plan document created:** `docs/plan_per_pair_params.md`

### 2. Fix: Backtest no longer skips cycles outside allowed_trading_hours (closes #106)

**Bug:** `allowed_trading_hours.enabled=true` in config caused backtest to only call LLM during the 1-hour window (19:00–19:59 UTC). With 2,016-candle backtests, only ~84 LLM calls instead of ~2,016 — 96% fewer cycles.

**Fix:** `tests/test_backtest.py` — force `config["trading"]["allowed_trading_hours"]["enabled"] = False` after loading config, same pattern as DB path overrides.

### 3. Feat: Per-pair atr_tp_min_pct — replaces broken global 1.0% floor (refs #107)

**Problem:** Global `dynamic_tp.atr_tp_min_pct: 1.0%` permanently blocks all pairs in normal conditions (BTC median ATR% is 0.21%, no pair median reaches 1.0%).

**Fix:**
- `config.yaml`: Added `atr_tp_min_pct` to every pair in `trading.pairs[]`. Values derived from `p25 ATR% × 0.8` with 0.10% min cap: BTC=0.14, ETH=0.23, BNB=0.15, SOL=0.30, XRP=0.26, TRX=0.12, DOGE=0.31, ADA=0.32, LTC=0.26, AVAX=0.31, SUI=0.37, UNI=0.30, INJ=0.34
- `src/analysis/signals.py` Hard Blocker 2: reads `indicators["adaptive_atr_floor_pct"]` (injected) → `pair_cfg["atr_tp_min_pct"]` (per-pair) → `dynamic_tp.atr_tp_min_pct` (global) → `min_profit_floor_pct` fallback
- `dynamic_tp.atr_tp_min_pct` global fallback lowered from 1.0 → 0.30

### 4. Feat: Per-pair rsi_oversold and rsi_overbought thresholds (refs #109)

**Problem:** Single global threshold treats all pairs identically. TRX fires RSI<30 on 6.87% of candles (noisy); BNB only 3.48% (too rare). Global 75 overbought means XRP/DOGE/ADA/LTC/SUI/INJ almost never trigger it.

**Fix:**
- `config.yaml`: Added `rsi_oversold` and `rsi_overbought` to every pair
- `src/analysis/signals.py`: `generate_signal()` looks up `pair_cfg` first, falls back to global `indicators.rsi_oversold/overbought`
- Values: BNB/XRP/LTC oversold→28, TRX→35, others→30; TRX overbought→65, XRP/DOGE/ADA/LTC/SUI/INJ→72, others→75

### 5. Feat: Per-pair bb_squeeze_threshold_pct (refs #110)

**Problem:** Global 1.0% squeeze threshold correct only for BTC/TRX. SOL/SUI/UNI/INJ have p10 BB width of 1.75–2.5% — current threshold incorrectly declares them in squeeze most of the time, clamping dynamic TP to minimum.

**Fix:**
- `config.yaml`: Added `bb_squeeze_threshold_pct` to every pair (from p10 BB width data)
- `src/analysis/features.py:compute_dynamic_tp()`: reads `pair_cfg["_rolling_bb_p10_pct"]` (adaptive, injected) → `pair_cfg["bb_squeeze_threshold_pct"]` (per-pair) → `dynamic_tp.squeeze_threshold_pct` (global)
- Values: BTC=0.7, ETH=1.3, BNB=0.9, SOL=1.8, XRP=1.4, TRX=0.8, DOGE=1.8, ADA=1.9, LTC=1.5, AVAX=2.0, SUI=2.1, UNI=2.1, INJ=2.5
