# Session Notes — 2026-04-11 (Part W)

## Changes

### 1. Feat: tiered per-pair slippage in paper broker (#204)

**Feature request:** Simulate realistic Kraken slippage per asset class. Thin-traded meme coins have much higher fill slippage than sat-level liquid blue chips. A flat 0.05% global rate under-estimates friction for speculative pairs.

**Implementation:**

**`config.yaml`** — added `slippage_pct` and `pair_tier` to every active pair entry:

| Tier | Pairs | `slippage_pct` |
|---|---|---|
| 1 (macro reserve) | BTC | 0.05% |
| 2 (L1 infrastructure) | ETH, BNB, SOL, XRP, ADA, LTC, AVAX | 0.05–0.10% |
| 3 (speculative altcoins) | TRX, SUI, HYPE, UNI, INJ, TON, OP, ARB, TIA, RENDER, FET, STX, PENDLE, ONDO | 0.20% |
| 4 (meme/momentum) | DOGE, WIF, JUP, PEPE, BONK | 0.40% |

`pair_tier` field also added now to serve #203 (sector rotation).

Added to `regime:` section: `btc_dominance_rising_caution_multiplier: 0.7`, `tier3_dominance_rising_multiplier: 0.5`, `tier4_dominance_rising_multiplier: 0.3`, `btc_dominance:` sub-block (for #206).

Added to `risk:` section: `cycle_top_guard:` block (MVRV Z-score / NUPL thresholds, cache TTL, for #205).

**`src/exchange/paper_broker.py`:**
- Added `_get_pair_slippage(pair: str) -> float` — looks up `trading.pairs[].slippage_pct`, falls back to global `self._slippage`
- `place_order()`: uses `slip = self._get_pair_slippage(pair)` for entry fill; `"slippage_pct": slip * 100` in returned dict now reflects actual per-pair value
- `close_position()`: uses `slip = self._get_pair_slippage(pos.get("pair", ""))` for exit fill

**`tests/test_entry_slippage.py`:**
- Added `_make_broker_with_pair_cfg()` helper — creates broker with a single `trading.pairs` entry
- Added `class TestPerPairSlippage` with 9 new test cases:
  - `_get_pair_slippage()` returns correct fraction for all 4 tiers (BTC, ADA, TRX, WIF)
  - Fallback to global when pair not in config
  - `place_order()` fill price and returned `slippage_pct` reflect per-pair config
  - `close_position()` exit fill reflects per-pair slip
  - Round-trip cost comparison: meme (0.4%) worse PnL than large-cap (0.05%) at same exit price
- Total: 12 tests (3 original + 9 new), all passing

**Closes:** #204
