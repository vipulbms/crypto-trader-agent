## Changes

### 1. Commit skill: branch + PR workflow (#168)

**Bug report / Feature request:**
User requested all commits go on a `feature/<N>` or `defect/<N>` branch, never directly to
`main`, with a pull request raised after each push.

**Root cause / Motivation:**
Previous skill committed directly to `main`. Branch-based development improves traceability,
enables code review, and prevents accidental pushes of incomplete work.

**Fix / Implementation:**

`.claude/skills/commit/SKILL.md`:
- **New Step 1** (inserted before old step 1): create branch from `main`.
  - Bug fix / regression → `defect/<issue-number>` (e.g. `defect/173`)
  - Feature / enhancement → `feature/<issue-number>` (e.g. `feature/165`)
  - Commands: `git checkout main && git pull && git checkout -b feature/<N>`
  - If branch already exists: `git checkout feature/<N>`
  - Requires GitHub issue to exist first (per mandatory workflow rule).
- **Step 10** updated: `git push -u origin feature/<N>` (was `git push` to main).
- **New Step 11**: `gh pr create --repo vipulbms/crypto-trader-agent --base main --head feature/<N> --title "..." --body "Closes #<N>"`. Includes fallback compare URL if `gh` unavailable.
- **Step 12** updated: confirm reports commit hash, branch name, and PR URL.
- All middle steps renumbered 2–9 accordingly (content unchanged).

User memory (`/memories/kryptos_workflow.md`) also updated to reflect the new
`Investigate → Issue → Branch → Fix → Test → Commit → Push → PR → Merge` workflow.
