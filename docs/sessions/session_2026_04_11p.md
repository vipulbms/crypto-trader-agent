# Session Notes — 2026-04-11 (Part P)

## Changes

### 1. Fix: SOD balance DB-persisted in live mode — midnight rollover (#178)

**Bug report:** `_get_or_set_sod_balance()` was only invoked when `mode == "paper"`. In live mode,
`start_of_day_bal` was captured once at startup and never refreshed, so the midnight UTC rollover
was silently ignored. Any run crossing 00:00 UTC in live mode always computed daily P&L against the
stale startup balance.

**Root cause / Motivation:**

Two sub-issues:

1. `PAPER_SCHEMA` and `LIVE_SCHEMA` in `src/storage/database.py` never declared the `agent_state`
   table. The table existed in the production `paper_trading.db` because it had been created
   ad-hoc by a prior migration run, but it was never codified in the schema DDL.  Calling
   `init_live_db()` on a fresh DB would therefore not create `agent_state`, and any live-mode
   attempt to read/write the SOD key would fail silently.

2. The SOD refresh block in `main.py` was guarded by `if mode == "paper" and not is_backtest:`,
   meaning live mode always relied on the in-memory `start_of_day_bal` set at agent startup.

**Fix / Implementation:**

*`src/storage/database.py`*
- Added `agent_state` table DDL to the end of `PAPER_SCHEMA`:
  ```sql
  CREATE TABLE IF NOT EXISTS agent_state (
      key   TEXT PRIMARY KEY,
      value TEXT NOT NULL
  );
  ```
- Added the same DDL to the end of `LIVE_SCHEMA`.
- Added `"CREATE TABLE IF NOT EXISTS agent_state (key TEXT PRIMARY KEY, value TEXT NOT NULL)"` to
  the migrations list in both `init_paper_db()` and `init_live_db()` — these migrations are
  idempotent (`CREATE TABLE IF NOT EXISTS`), so they are safe on both fresh and existing DBs.

*`main.py`*
- Renamed parameter `paper_db` → `db_path` in `_get_or_set_sod_balance()` and updated its
  docstring to remove the "paper mode only" restriction.
- Updated the function body to use `get_connection(db_path)` (trivial rename).
- Changed the SOD refresh condition from `if mode == "paper" and not is_backtest:` to
  `if not is_backtest:`, with an inner `if/else` that selects the correct DB path:
  - `mode == "paper"` → `config["storage"]["paper_db"]` (default `paper_trading.db`)
  - otherwise → `config["storage"]["live_db"]` (default `live_trading.db`)
- Updated inline comment reference from `(#170)` to `(#170, #178)`.

**Tests:** `tests/test_sod_balance.py` — 9 new tests across 3 classes:
- `TestAgentStateTableExists` — verifies `agent_state` is created by both `init_paper_db` and
  `init_live_db`, and that double-init is idempotent.
- `TestSodBalanceLiveMode` — first-call write, same-day stability, midnight UTC rollover (new key
  written on new UTC date), graceful fallback on DB unavailability.
- `TestSodBalancePaperMode` — same-day stability and midnight rollover still work in paper mode.

All 199 tests pass.
