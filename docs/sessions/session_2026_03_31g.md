# Session Notes — 2026-03-31 (Part G)

## Changes

### 1. Telegram Notification — Added Invested USD Amount

**Bug report:** ETH worth $2000 appeared to be bought with only $1000 balance.

**Root cause (not a real bug):** The Telegram opening trade notification showed:
```
Fill: $2020.96 | Vol: 0.069274
```
`Fill` is the **market price per coin** (ETH costs ~$2020/coin), not the USD amount invested. The notification had no invested amount field, making it easy to confuse the coin price with the trade size. Actual investment was $140.

**Fix:** Added `Invested: $X.XX` to the opening trade notification line.

**Before:**
```
[PAPER] 🟡 BUY: ETH/USD
Fill: $2020.96 | Vol: 0.069274
SL: $1919.91 | TP: $2263.48
```

**After:**
```
[PAPER] 🟡 BUY: ETH/USD
Fill: $2020.96 | Vol: 0.069274 | Invested: $140.00
SL: $1919.91 | TP: $2263.48
```
