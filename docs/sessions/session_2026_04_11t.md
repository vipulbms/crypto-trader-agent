# Session Notes — 2026-04-11 (Part T)

## Changes

### 1. Drawdown Recovery Mode (#182)

**Feature request:** Add a defensive trading band at -3% daily loss to prevent the failure pattern: alts hit SL → circuit breaker resets → agent re-enters same alts → portfolio hits -7% kill switch.

**Motivation:** Nothing existed between normal trading and the 10% kill switch. When SUI/JUP/WIF hit stop-losses during a risk-off move at -3%, the agent would re-enter the same volatile alts, compounding the loss until the -7% global kill switch triggered a panic-sell of all positions at the worst point of the day.

**Implementation:**

- **`config.yaml`** — Added `risk.drawdown_recovery` block after `circuit_breaker`:
  ```yaml
  drawdown_recovery:
    enabled: true
    trigger_pct: 3.0           # Enter recovery at -3% daily loss
    exit_pct: 1.5              # Exit when recovered to -1.5% (hysteresis band)
    allowed_pairs: [BTC/USD, ETH/USD, BNB/USD]
    max_position_pct_override: 10  # Half of normal 20% max during recovery
  ```

- **`src/risk/risk_manager.py`**:
  - `__init__`: loaded `drawdown_recovery` config into `self._recovery_*` attributes
  - Added `is_in_drawdown_recovery(daily_pnl_pct: float) -> bool` — stateless check: returns `True` when `pnl_pct <= -trigger_pct`
  - `validate_buy()`: Added Guard 1.2 (after daily loss check, before cash reserve check). Rejects non-major pairs; caps position size to `available_cash × max_position_pct_override / 100`

- **`src/notifications/notifier.py`**:
  - Added `send_drawdown_recovery_entered(daily_pnl_pct, allowed_pairs)` — sends ⚠️ alert on entry
  - Added `send_drawdown_recovery_exited(daily_pnl_pct)` — sends ✅ alert on exit

- **`main.py`** — `run_cycle()`: Added recovery state tracking using hysteresis in `loop_state["drawdown_recovery_active"]`. Sends entry/exit notifications only on state transitions. Hysteresis: enter when pnl ≤ -trigger, exit only when pnl > -exit_pct (avoids re-entry oscillation in the -3% to -1.5% band).

- **`tests/test_drawdown_recovery.py`** (new) — 7 tests:
  - Non-major pair rejected at -3.5%
  - BTC/USD approved at half size at -3.5%
  - Recovery not active at -1.0%
  - Recovery not triggered at -2.9%
  - Disabled config ignores threshold
  - Exact boundary at -3.0%
  - ETH/USD (allowed pair) approved in recovery
