DAILY OPERATIONS
════════════════════════════════════════════════════════════════════════════════

  Start all services:              ./scripts/manage_services.sh start
  Stop all services:               ./scripts/manage_services.sh stop
  Restart everything:              ./scripts/manage_services.sh restart
  Check service status:            ./scripts/manage_services.sh status
  Verify health + check logs:      ./scripts/manage_services.sh verify
  View logs:                       ./scripts/manage_services.sh logs [service] [N]

EXAMPLES
  ./scripts/manage_services.sh logs all 50             # All services, 50 lines
  ./scripts/manage_services.sh logs audit_agent 100    # Audit only, 100 lines


BACKGROUND MONITORING (Auto-Restart)
════════════════════════════════════════════════════════════════════════════════

  One-time health check:           ./scripts/healthcheck.sh
  With auto-restart:               ./scripts/healthcheck.sh --auto-restart
  With Telegram alerts:            ./scripts/healthcheck.sh --telegram
  Full monitoring:                 ./scripts/healthcheck.sh --auto-restart --telegram

CRON SETUP (Every 5 Minutes)
  crontab -e
  */5 * * * * cd /path/to/repo && ./scripts/healthcheck.sh --auto-restart --telegram >> logs/healthcheck.log 2>&1

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

  Services won't start?
    → ./scripts/manage_services.sh verify
    → ./scripts/manage_services.sh logs all 100

  Services running but errors?
    → grep -i error logs/*.log | tail -20
    → ./scripts/manage_services.sh logs [service] 200

  Auto-restart not working?
    → tail logs/healthcheck.log
    → Check: crontab -l

PRODUCTION SETUP (RECOMMENDED)
════════════════════════════════════════════════════════════════════════════════

  Step 1: Start services
    ./scripts/manage_services.sh start

  Step 2: Set up monitoring (crontab -e)
    */5 * * * * cd /path/to/repo && ./scripts/healthcheck.sh --auto-restart --telegram >> logs/healthcheck.log 2>&1

  Step 3: Optional - Daily restart at 2 AM
    0 2 * * * cd /path/to/repo && ./scripts/manage_services.sh restart >> logs/cron-restart.log 2>&1

  That's it! Services will auto-restart on failure and you'll get Telegram alerts.


KEY FEATURES
════════════════════════════════════════════════════════════════════════════════

  • Start/stop/restart all services with one command
  • Graceful shutdown (waits 30s before force kill)
  • Process verification after startup
  • Log error detection (ERROR, EXCEPTION, FATAL, etc.)
  • Activity monitoring (detects stalled services)
  • Auto-restart with limits (up to 3 attempts)
  • Telegram notifications (failures, restarts)
  • Color-coded output (easy to read)
  • Service health status tracking
  • Comprehensive logging to logs/healthcheck.log
